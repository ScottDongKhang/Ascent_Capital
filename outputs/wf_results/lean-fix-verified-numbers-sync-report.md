## Step 3 — `scripts/verify_docs.py` fix

`check_verified_numbers_matches_artifact()` previously hardcoded:
```python
art_rel = "outputs/wf_results/wf_report_clean_2026-06-22.json"
```

Changed to import the pointer dynamically:
```python
if str(ROOT) not in sys.path:
    sys.path.insert(0, str(ROOT))
try:
    from ascent.reporting.verified_numbers import CANONICAL_WF_ARTIFACT
except ImportError as exc:
    return False, f"could not import CANONICAL_WF_ARTIFACT: {exc}"
art_rel = CANONICAL_WF_ARTIFACT
```

This makes the doc-guard structurally unable to drift from the loader again — it now checks
"does the doc match whatever `canonical_wf()` actually reads" rather than "does the doc match
a filename someone once typed into the guard."
